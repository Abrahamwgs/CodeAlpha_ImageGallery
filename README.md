## Image Gallery

A modern responsive image gallery built using HTML, CSS, and JavaScript.

## Features
- Responsive Grid Layout
- Category Filtering
- Animated Loading
- Lightbox Preview
- Next/Previous Navigation
- Image Captions
- Smooth Hover Effects
- Premium Glassmorphism UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
